# 🐱 猫国建设者全能小助手 (Kittens Game Auto Assist)

[![Tampermonkey](https://img.shields.io/badge/Requires-Tampermonkey-yellow)](https://www.tampermonkey.net/)
[![Version](https://img.shields.io/badge/Version-v7.8.24-blue)](https://github.com/DearPeter/kittens-game-script)
[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

基于 [Kittens Game](https://kittensgame.com/web/) 的油猴自动化脚本，提供资源管理、自动合成、智能贸易等功能。

---

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 🎨 **Material Design UI** | 蓝色悬浮球 🐱，支持拖拽，一键全局开关 |
| 🦄 **独角兽自动化** | 模拟点击，自动升级牧场（解决游戏API限制） |
| ⚡ **智能阈值模式** | 打猎/交易/手稿/概要/蓝图支持「定时」或「阈值」双模式 |
| 🔄 **资源自动合成** | 木材→木梁、铀→钍等 11 种资源转化 |
| 🤝 **智能级联交易** | P1→P2→P3 优先级自动切换，最大化资源利用 |
| 🌌 **虚空主宰(列维坦)** | 优先交易、自动喂食 |
| 📂 **配置档案管理** | 保存/切换多套配置（挂机模式、冲刺模式等） |
| ☁️ **定时云存档** | 每 10 分钟自动保存 |

## 📦 支持的功能列表

### 🟢 Tab 1: 资源转化

| 资源链 | 阈值类型 | 默认值 | 说明 |
|--------|----------|--------|------|
| 木材 → 木梁 | 百分比 | 90% | 上限的 90% 时自动合成 |
| 矿物 → 石板 | 百分比 | 90% | - |
| 煤炭 → 钢铁 | 百分比 | 90% | - |
| 铁 → 金属板 | 百分比 | 90% | - |
| 猫薄荷 → 木头 | 百分比 | 90% | 过剩转化 |
| 石油 → 煤油 | 百分比 | 90% | - |
| 难得素 → E合金 | 百分比 | 90% | - |
| 钛 → 合金 | 百分比 | 90% | - |
| 铀 → 钍 | 百分比 | 90% | 防止铀溢出 |
| 木梁 → 脚手架 | 固定值 | 10000 | 达到数量自动合成 |
| 毛皮 → 羊皮纸 | 固定值 | 15000 | - |

### ⚡ Tab 2: 自动活动

| 功能 | 模式 | 说明 |
|------|------|------|
| 自动点星图 | 开关 | 定时点击"观测天空" |
| 自动升级独角兽牧场 | 开关 | 模拟点击按钮升级 |
| 自动派猎人 | **定时 / 阈值** | 打猎获取喵力 |
| 智能猎人 (金满停/低开) | 开关 | 金满+资源充足时暂停 |
| 自动赞美太阳 | 定时 (60分钟) | 获取信仰 |
| 自动合成手稿 | **定时 / 阈值** | 文化 → 手稿 |
| 自动合成概要 | **定时 / 阈值** | 科学 → 概要 |
| 自动合成蓝图 | **定时 / 阈值** | 科学 → 蓝图 |
| 定时云存档 | 定时 (10分钟) | 自动保存进度 |

**阈值模式说明：**
- 选择「定时」：每隔 X 分钟执行一次
- 选择「阈值」：当资源达到上限的 X% 时立即执行（推荐后期使用）

### ⚖️ Tab 3: 贸易外交

| 功能 | 说明 |
|------|------|
| 紧急交易鲨鱼 | 猫薄荷 < 阈值时交易 1 次 |
| 自动交易 | **定时 / 阈值** 模式 + 选择目标种族 |
| 智能级联交易 | P1→P2→P3 自动切换 |
| 优先交易列维坦 | 难得素 > 15k 时暂停 E 合金，优先交易 |
| 自动喂食死角兽 | necrocorn ≥1 时自动喂食 |

**智能级联交易逻辑：**
```
P1 (如龙族换铀) 满 → P2 (斑马换钛) → P3 (鲨鱼换猫薄荷)
```

### 📂 Tab 4: 档案管理

- **保存配置**：命名当前所有设置
- **读取配置**：一键切换（如"挂机模式"、"冲刺模式"）
- **删除配置**：移除存档

## 🚀 安装指南

### 第一步：安装 Tampermonkey

| 浏览器 | 安装地址 |
|--------|----------|
| Chrome / Edge | [Chrome 网上应用店](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) |
| Firefox | [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/tampermonkey/) |

### 第二步：安装脚本

**方式 A：通过链接安装（推荐）**
1. 点击 [这里安装脚本](https://raw.githubusercontent.com/DearPeter/kittens-game-script/main/auto.js)
2. Tampermonkey 会弹出安装界面
3. 点击「安装」

**方式 B：手动安装**
1. 点击 Tampermonkey 图标 → 「添加新脚本」
2. 删除默认代码，粘贴 `auto.js` 全部内容
3. 按 `Ctrl + S` 保存

## 📖 使用说明

### 1. 启动界面

- 进入游戏后，右下角出现蓝色悬浮球 🐱
- 点击悬浮球打开设置面板
- 顶部「全局开关」控制所有自动化（蓝色=开启）

### 2. 功能配置

每个功能都有独立开关，部分支持「定时/阈值」双模式切换。

### 3. 调试技巧

- **F12** 打开浏览器控制台，查看详细日志
- 日志会显示当前配置、运行状态、游戏资源快照

## ❓ 常见问题 (FAQ)

**Q: 独角兽牧场不自动升级？**
A: 确保按钮可见且资源足够。脚本通过模拟点击实现，按钮灰色/隐藏时不会执行。

**Q: 喵力回复太快，一秒就满？**
A: 将「自动派猎人」切换为「阈值」模式，设置为 95% 或 98%。这样一满就触发。

**Q: 脚本不工作了？**
A:
1. 检查全局开关是否开启（蓝色）
2. 刷新网页
3. F12 查看控制台报错
