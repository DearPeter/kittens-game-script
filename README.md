🐱 猫国建设者全能小助手 (Kittens Game Auto Assist)
版本: v7.8.17 (Google Material UI + 喵力阈值版)
适用游戏: Kittens Game (猫国建设者)
这是一个基于 Tampermonkey (油猴) 的自动化脚本，旨在为《猫国建设者》提供便捷的资源管理、自动合成、自动贸易和智能操作功能。v7.8.17 版本采用了全新的 Google Material Design 风格界面，并针对后期游戏进行了深度优化。
✨ 核心功能
🎨 全新 UI: 清爽的 Material Design 风格，支持拖拽，带有一键全局开关。
🦄 独角兽自动化: 采用模拟点击技术，自动购买/升级独角兽牧场（解决游戏API限制问题）。
⚡ 智能喵力阈值: 打猎和贸易支持「喵力阈值 (Cap%)」模式，当喵力快满时瞬间触发，彻底解决后期喵力溢出问题。
🔄 资源自动合成: 支持木材、矿物、煤炭、铁、钛、铀等多种资源的自动转化（基于容量百分比）。
🤝 智能级联贸易: 支持优先级设置（如：优先换铀，满了换钛，最后换猫薄荷），实现资源最大化利用。
🛠️ 辅助功能: 自动点星图、自动赞美太阳、自动合成手稿/蓝图、定时云存档。
📂 档案管理: 支持保存多套配置方案（如“挂机模式”、“冲刺模式”），一键切换。
🚀 安装指南
第一步：安装浏览器扩展
你需要先安装 Tampermonkey (篡改猴) 扩展程序。
Chrome / Edge: 前往 Chrome 网上应用店 下载。
Firefox: 前往 Firefox Add-ons 下载。
第二步：安装脚本
您可以选择以下两种方式之一：
方式 A：手动新建脚本 (推荐)
点击浏览器右上角的 Tampermonkey 图标，选择 “添加新脚本...”。
删除编辑器中现有的所有代码。
将 auto.js 中的全部代码复制并粘贴到编辑器中。
按 Ctrl + S (或点击“文件”->“保存”)。
方式 B：通过链接安装 (如果您的 GitHub 是公开的)
点击 这里安装脚本 (前提是您已将代码 push 到 GitHub)。
Tampermonkey 会自动弹出安装界面，点击 “安装” 即可。
📖 使用说明
1. 启动与界面
进入游戏后，右下角会出现一个蓝色的悬浮球 🐱。
点击悬浮球即可打开设置面板。
全局开关：面板标题旁的滑块是总开关，关闭后脚本将暂停所有自动化操作。
2. 功能页签详解
🧱 资源转化 (Resources)
这里控制基础资源的自动合成。
百分比滑块 (如 90%)：当资源数量达到存储上限的 90% 时，脚本会自动将多余的资源合成（例如：木材 -> 木梁）。
建议保留 90%-95%，以防手动操作时资源不足。
铀 -> 钍: 防止铀溢出，自动合成钍。
⚡ 自动活动 (Activities)
自动点星图: 自动点击观测天空。
自动升级独角兽牧场: 模拟鼠标点击，只要资源足够且按钮可见，自动升级牧场。
自动派猎人 (重点更新):
定时模式 (Interval): 每隔 X 分钟派一次猎人。
喵力模式 (Threshold): (推荐) 当喵力达到上限的 X% (如 95%) 时，立即派猎人。适合后期喵力回复极快的情况。
智能猎人 (Smart Hunter): 如果开启，当黄金已满且毛皮/象牙充足时，暂停打猎以节省喵力用于贸易。
⚖️ 贸易外交 (Trade)
自动交易: 同样支持 定时 和 喵力阈值 两种模式。
智能级联交易 (Smart Cascade):
P1 (优先级1): 首选交易对象（通常设为龙族换铀）。
P2 (优先级2): 当 P1 资源（铀）满后，自动切换到 P2（通常设为斑马换钛）。
P3 (兜底): 当 P1、P2 都满后，与 P3 交易（通常设为鲨鱼换猫薄荷）。
📂 档案管理 (Profiles)
输入名称点击 保存，可将当前所有勾选状态和阈值保存下来。
点击 读取 可快速切换配置（例如白天用“活跃模式”，晚上睡觉用“挂机模式”）。
3. 调试功能
如果在游戏中按下 F12 键，浏览器的控制台 (Console) 会输出当前脚本的详细运行状态、配置参数和游戏资源快照，方便排查问题。
❓ 常见问题 (FAQ)
Q: 为什么独角兽牧场不自动升级？
A: 请确保您在游戏界面中能看到“独角兽牧场”的按钮，并且资源（独角兽）足够。脚本是通过模拟点击按钮来实现的，如果按钮是灰色的或者未解锁，则不会执行。
Q: 喵力回复太快，一秒钟就满了怎么办？
A: 请在“自动活动”页签中，将“自动派猎人”的模式从“定时”切换为 “喵力” (Threshold)，并将滑块设置为 95% 或 98%。这样只要一满就会自动触发，无视时间间隔。
Q: 脚本不工作了怎么办？
检查面板顶部的 “全局开关” 是否开启（蓝色为开启）。
刷新网页。
按 F12 查看控制台是否有红色报错信息。
